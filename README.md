# 🌪️ Sistema de Monitoramento e Prevenção de Tornados

Este repositório contém o código-fonte de um sistema voltado para o **monitoramento de condições meteorológicas** e a **orientação preventiva em casos de tornados**.  
O projeto foi desenvolvido com foco em fornecer informações confiáveis e acessíveis aos usuários, permitindo cadastro, login e acesso a dados meteorológicos e instruções de segurança.

---

## 📂 Estrutura do Projeto

- **`assets/`**  
  Diretório destinado ao armazenamento das pastas de **CSS** e **JavaScript**, responsáveis pela estilização e interatividade do sistema.

- **`config/`**  
  Contém os arquivos de configuração do **Banco de Dados**.

- **`SQL/`**  
  Inclui os scripts SQL utilizados para criação e manutenção da base de dados.

- **`cadastro.php`**  
  Página destinada ao **cadastro de usuários**, coletando informações como email e cidade.

- **`index.php`**  
  Página de **login**, que utiliza email e senha como credenciais de acesso.

- **`mapa.php`**  
  Exibe um **mapa interativo** das cidades cadastradas, centralizado na cidade selecionada pelo usuário durante o login.

- **`passo_a_passo.php`**  
  Página informativa que apresenta um **guia básico de procedimentos** a serem adotados em situações de risco de tornados, bem como orientações pós-evento.

- **`prevensaoSite.php`**  
  Página que disponibiliza **dados meteorológicos da cidade selecionada**, incluindo velocidade dos ventos, umidade e outros indicadores relevantes.

---

## 🚀 Funcionalidades Principais

- Cadastro e autenticação de usuários  
- Visualização de mapas interativos com foco na cidade do usuário  
- Exibição de dados meteorológicos atualizados  
- Guia de prevenção e instruções pós-evento  

---

## 🛠️ Tecnologias Utilizadas

- **PHP** – Backend e lógica de aplicação  
- **MySQL** – Banco de dados relacional  
- **JavaScript** – Interatividade e manipulação dinâmica de elementos  
- **CSS** – Estilização e layout das páginas  
- **HTML** – Estruturação das páginas web
